# UA Deck Lab — MVP

一個不依賴後端即可直接執行的 UNION ARENA 卡片搜尋 / 組牌 / 推薦原型。

## 執行
直接開啟 `index.html`，或在此資料夾執行：

```bash
python3 -m http.server 8080
```

瀏覽器開啟 `http://localhost:8080`。

## 已完成
- 卡片名稱 / 效果搜尋
- 顏色與作品篩選
- 卡片詳細資訊
- 加入 / 移除牌組，單卡上限 4
- 50 張牌組進度與簡易能源曲線健檢
- 以核心卡為起點的 synergy 推薦
