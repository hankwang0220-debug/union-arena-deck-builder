## 使用

直接開啟 `index.html`，或執行 `python -m http.server 8080 --bind 127.0.0.1` 後開啟 `http://localhost:8080`。

- 依作品、顏色、類型、收錄商品、稀有度、特徵、效果、觸發及數值篩選；每頁 30 張。
- 主牌組最多 50 張、同卡號通常最多 4 張；限制卡依日本官方公告最多 1 或 2 張。AP 最多 3 張且獨立計數。
- 使用限制資料在 `data/rules.js`，核對日期 2026-10-06，含 2026-10-01 生效公告；已收錄官方限制卡並套用對應張數上限。
- 「輔助標記」頁面提供 BP 計數器與效果標記分類、用途及官方說明連結，不加入牌組。
- 跨作品卡組會顯示提示；點開卡片即顯示同作品搭配卡，優先依 UPTCG 公開完整牌組的共同收錄次數推薦。
- 可新增、切換、改名多個牌組，名稱後保留 IP；牌組自動儲存於目前瀏覽器。價格選擇仍保存在本頁記憶體。
- 分頁旁可輸入頁碼並按 Enter 或「跳頁」。

## 價格

`prices.js` 保存先前核對的 121 個遊々亭商品價格，查價日期為 2026-10-05。
只配對同卡號的商品，不再依角色名稱混用不同能力卡片的價格。
使用者選擇商品版本後才計算小計；未查價／未選版張數及售罄張數會另行提示。
犬夜叉卡片尚未匯入價格。新補齊的卡片並非都有價格；售價為 JPY 快照，不會自動同步，不是買取價。
所有日幣金額旁顯示約新台幣價格，依 2026-10-06 匯率快照（1 JPY = 0.2010 TWD，Investing.com）換算，四捨五入至整元；總價先加總日幣再換算，匯率未自動更新。
目前每個卡號可選一種估價版本，該卡號全部張數使用同一單價。

## 檔案與驗證

- `index.html`、`styles.css`、`app.js`：介面及功能。
- `data/cards.json`：含來源、時間、完整卡片及印刷版本的可讀資料。
- `data/cards.js`：可直接用於靜態網站、離線開啟的資料檔。
- `prices.js`：售價快照與價格配對。
- `scripts/import-official.py`：Python 標準函式庫匯入器；最多 8 個並行請求，支援中斷續傳快取及欄位檢查。
- `scripts/verify-data.cjs`：執行 `node scripts/verify-data.cjs`，核對數量、編號完整性、特殊數值、篩選、價格與組牌限制。

重新整理官方快照：`python scripts/import-official.py --refresh`；不加 `--refresh` 會使用 `.cache/official` 的已有頁面。`updatedAt` 為資料產生時間，重用快取並不代表重新查閱網站。未來新增卡片後須同步更新測試的卡表數量及收錄範圍。

GitHub Pages 發布需包含 `index.html`、`styles.css`、`app.js`、`prices.js`、`data/cards.js`、`data/rules.js`、`data/images.js` 與 `assets/cards/`。本機修改不會自動推送 GitHub。

## UPTCG 牌組搭配參考

推薦快照來源：[UPTCG 玩家社群](https://uptcg.app/unionarena/community)，2026-10-07 匯入 892 個公開牌組，保留 712 種不同的完整組合，涵蓋 52 個 IP、3186 個主牌組卡號。僅保存牌組名稱、代碼、公開時間、來源與卡號張數；不保存帳號、玩家個資或第三方卡片效果全文。

點開卡片時，在詳情上方顯示最多六張常見搭配卡，可直接查看或加入目前牌組。排序以共同收錄的牌組數為主，相同次數才使用原有相似度排序；比例的分母是收錄目前卡片的不同完整牌組數。每張搭配卡顯示收錄張數範圍、最多三個參考牌組名稱與代碼；來源連結開啟 UPTCG 社群，可輸入代碼核對。這是社群組牌資料，不是勝率或賽事排名。

匯入時將官方商品前綴與異圖後綴正規化為本機卡號，要求主牌組恰為 50 張、同作品、每個卡號最多 4 張，排除 AP、預覽卡、未知卡號及重複組合。歷史牌組可能早於目前限卡公告；實際加入仍遵守本站最新限制。未收錄的卡片會明確顯示「尚無牌組紀錄」，改用同作品的顏色、特徵及效果相似度參考。

資料檔為 `data/reference-decks.json` 與 `data/reference-decks.js`，推薦邏輯及介面在 `recommendations.js`。網站離線可用，不向第三方傳送使用者牌組，也不會自動同步來源。執行 `node scripts/import-uptcg-decks.cjs` 可更新公開快照；來源讀取失敗時保留舊資料。發布時須包含上述三個檔案。執行 `node scripts/verify-recommendations.cjs` 驗證完整性、去重、共同收錄統計、IP 隔離、推薦排序及缺少資料的提示。

卡片列表也直接顯示前三張搭配卡的小圖、名稱、卡號、共同收錄次數與張數範圍，可用「＋」加入目前牌組。滑過縮圖或以鍵盤聚焦可預覽完整卡圖；手機可直接閱讀搭配資訊。「展開更多搭配與來源」在原卡片下方展開其餘搭配及參考牌組代碼，不切換頁面或重設搜尋。

## 牌組分享網址

在「我的卡組」按「產生牌組分享網址」，再複製網址或加入書籤。網址片段 `#deck=...` 保存版本、UTF-8 牌組名稱、IP 與全部卡號張數（含 AP），可跨瀏覽器還原，不需帳號或後端。開啟後自動切換至牌組並另存到目前瀏覽器，保留原有牌組；完全相同的牌組重開時不重複新增。

分享連結是產生當下的快照，後續修改須產生新連結。未知卡號、損毀連結或非法張數會顯示錯誤，整個牌組不會部分匯入。歷史牌組若遇限卡規則更新仍保留原始張數供核對。正式分享請從已發布的網站產生連結，本機 localhost 及 file 網址僅供本機驗證。發布需包含 `deck-sharing.js`；執行 `node scripts/verify-deck-sharing.cjs` 驗證還原。
